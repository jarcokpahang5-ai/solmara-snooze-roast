A one-line roast of an alarm clock ringing at 6 AM on a Saturday, written for make.fun's "Snooze Button Roast" bounty ($2 in USDC). The entry program writes a single line to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

## The entry

> My alarm clock rings at 6 AM on a Saturday with the confidence of a man who has never once been right about what day it is.
